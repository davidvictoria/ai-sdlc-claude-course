programa. Si el practitioner indicó un documento o slides compartidos, usa

y sirve como respaldo. No es un artefacto evaluado por `npm run verify`.

Regla para todas las capturas: sin secretos, sin tokens, sin rutas
personales completas y sin datos reales. Todo el dominio de este
repositorio es sintético.

## Cómo tomar las capturas

- **macOS:** `Cmd + Shift + 4` y arrastrar sobre el área; la imagen queda
  en el escritorio. `Cmd + Shift + 5` abre opciones de grabación y
  ubicación.
- **Windows:** `Win + Shift + S` y arrastrar sobre el área; la imagen queda
  en el portapapeles y en Recortes. Pégala con `Ctrl + V` en el portafolio.
- **Terminal muy larga:** captura solo el bloque relevante (el plan, el
  `diff --stat`, el final de `npm run verify`). Si hay que recortar, mejor
  dos capturas cortas que una ilegible.
